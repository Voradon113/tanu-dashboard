# Gold Flow — อ่านการเปลี่ยนแปลงข้ามช็อต

ภาพเดียวบอกได้แค่ "ตอนนี้เป็นยังไง" — **หลายภาพบอกว่า "กำลังไปทางไหน"** ซึ่งมีค่ากว่ามาก
เพราะ flow ไม่ได้บอกทิศจากตัวเลขนิ่งๆ แต่บอกจาก **อัตราการเปลี่ยนแปลง**

สกิลนี้ใช้ต่อจาก `gold-options-flow` (ที่อ่านภาพแรก) — ถ้าเป็นภาพแรกของสัญญานั้น กลับไปใช้อันนั้นก่อน

---

## ขั้น 0 — เช็คก่อนว่าอะไรสด อะไรแช่แข็ง

**สำคัญที่สุดและคนพลาดบ่อยที่สุด** QuikStrike อัปเดตแต่ละส่วนคนละจังหวะ ถ้าไม่เช็คจะอ่านข้อมูลเมื่อวานเป็นของวันนี้

| ส่วน | สด? |
|---|---|
| ราคา · DTE · Future Chg | ✅ สด |
| แถบ Ranges / เส้น SD | ✅ คำนวณใหม่ตามราคา |
| **Intraday Volume** | ✅ วันนี้ |
| **OI · OI Change · Churn** | ❌ **เซสชันที่ปิดไปแล้ว** (CME ปล่อยวันละครั้งตอนเช้า) |
| **Vol / Vol Chg** | ❌ **ค่า settle** ไม่ใช่ IV สด (ป้ายบนกราฟเขียน "Vol Settle") |

### วิธีพิสูจน์ — ทำ 2 อย่างนี้ทุกครั้ง

**1. เทียบยอดรวมกับช็อตก่อน** ถ้าเลขเดิมเป๊ะทุกหลักทั้งที่เวลาผ่านไป = ไม่ได้อัปเดต

```
ช็อตก่อน:  Put 697 · Call 1,388 · Vol 28.08 · Vol Chg -0.07
ช็อตนี้ :  Put 697 · Call 1,388 · Vol 28.08 · Vol Chg -0.07   ← แช่แข็ง
```

**2. เช็คเลขคณิต OI vs Volume** — OI จะเปลี่ยนได้ต้องมีการเทรด ดังนั้น |OIΔ| ≤ Volume เสมอ

```
OI Change รวม 2,085  >  Intraday Volume รวม 478
⇒ OI ชุดนี้ไม่ใช่ของวันนี้แน่นอน
```

บอกผู้ใช้ตรงๆ ว่าส่วนไหนไม่ขยับ **และบอกว่าไม่ต้องดึงซ้ำแล้วจนกว่าจะพรุ่งนี้เช้า** จะได้ไม่เสียเวลา

> ⚠️ ถ้าสัญญา DTE < 1 วัน: OI ของวันนี้จะออกพรุ่งนี้ตอนที่สัญญาตายไปแล้ว
> **แปลว่าวันสุดท้ายจะไม่มีวันรู้ว่าใครซื้อใครขาย** — ต้องลดน้ำหนัก flow แล้วเพิ่มน้ำหนัก price action
> อย่าปล่อยให้ผู้ใช้รอข้อมูลที่จะไม่มีวันมา

## ขั้น 1 — ตารางเทียบช็อต

ทำทุกครั้ง ให้เห็นทิศทางในตาราง ไม่ใช่เล่าเป็นความเรียง:

```
                ช็อต1    ช็อต2    ช็อต3    ตอนนี้
DTE             0.45     0.42     0.39     0.38
Futures         4,110.6  4,101.5  4,098.2  4,085.6
Chg             -18.8    -27.9    -31.2    -43.8
Put             226      252      265      343  (+78)
Call            252      393      432      503  (+71)
C/P             1.12     1.56     1.63     1.47  ↓
1SD             40.7     38.8     37.6     36.1
```

**ดูที่ "ส่วนต่างระหว่างช็อต" ไม่ใช่ค่าสัมบูรณ์**
ตัวอย่างข้างบน: คอลยังนำในแง่ยอดรวม แต่ **พุทเพิ่งโตเร็วกว่าคอลเป็นครั้งแรก** (+78 vs +71) และ C/P เริ่มหักหัวลง — นั่นคือจุดที่เรื่องเล่า "คอลนำ" เริ่มพัง

## ขั้น 2 — 🎯 หัวใจของสกิล: วัดระยะ strike เป็นหน่วย SD ข้ามเวลา

$$\text{ระยะ} = \frac{|\,\text{strike} - \text{ราคา}\,|}{\text{1SD}}$$

**คำนวณค่านี้ทุกช็อต แล้วดูว่ามันวิ่งไปทางไหน** — นี่คือสิ่งที่ทำให้ฟันธงได้ว่า strike ไหนจบเกม

ที่มันได้ผลเพราะกรอบ SD **หดตามเวลาเสมอ** (theta) เพราะงั้นแม้ราคาจะเดินเข้าหา strike ระยะในหน่วย SD ก็อาจ *ไกลขึ้น* ได้ ถ้าราคาเดินช้ากว่าที่กรอบหด

**ตัวอย่างจริง — strike 4,175:**

```
ช็อต2:  (4175 - 4101.5) / 38.8 = 1.89 SD
ช็อต3:  (4175 - 4098.2) / 37.6 = 2.04 SD
ตอนนี้: (4175 - 4085.6) / 36.1 = 2.48 SD    ← ไกลขึ้นเรื่อยๆ
วอลุ่ม:  112  →  123  →  124                ← แต่ยังไหลเข้า (แล้วหยุด)
```

### ตารางตัดสิน

| ระยะ (SD) | อ่านว่า |
|---|---|
| < 1.0 | อยู่ในระยะเอื้อม — เป็นแม่เหล็กจริง |
| 1.0–2.0 | ยังมีลุ้น ต้องมีตัวเร่ง |
| 2.0–2.5 | เริ่มหลุดมือ ให้ลดน้ำหนัก |
| **> 2.5 + DTE < 0.5** | **จบเกม — ตัดออกจากสมการ** |

### 🔑 การอ่านที่มีค่าที่สุด: ระยะไกลขึ้น + วอลุ่มยังไหลเข้า

**คนซื้อไม่ทำแบบนี้ คนขายพรีเมียมทำ**

ผู้ซื้อออปชั่นต้องการให้ราคาวิ่งไปหา strike — พอโอกาสลดลงทุกชั่วโมง เขาจะหยุดซื้อหรือถอย
ส่วนคนขายกินพรีเมียมยิ่งเวลาผ่านยิ่งปลอดภัย เขาจะ **เติมเรื่อยๆ**

$$\text{ระยะ}\uparrow + \text{วอลุ่ม}\uparrow \;\Rightarrow\; \text{strike นั้นคือ "ฝา" ไม่ใช่ "เป้า"}$$

**เขียนคำเตือนคู่ไปด้วยเสมอ:** ยืนยันไม่ได้ 100% เพราะวอลุ่มไม่บอกฝั่ง bid/ask — แต่ให้บอกว่าน้ำหนักเอนไปทางไหนและเพราะอะไร ผู้ใช้ต้องการทิศทางที่มีเหตุผล ไม่ใช่ "ไม่รู้ครับ"

**เช็คงบเวลาประกอบ:** ต้องวิ่งกี่จุด ใน DTE ที่เหลือกี่ชั่วโมง — พูดเป็นตัวเลขตรงๆ เช่น *"ต้องขึ้น 90 จุดใน 9 ชั่วโมง"* ชัดกว่าคำว่า "ยาก"

## ขั้น 3 — ตัดตัวที่จบเกมออกก่อนคิด Bias

strike ที่ไปไม่ถึงแล้วยังค้างอยู่ในยอดรวม จะทำให้ภาพบิด **หักออกก่อนแล้วคิดใหม่**

```
รวม:        Call 503  vs  Put 343   →  C/P 1.47  (ดูเหมือนคอลนำ)
หัก 4,175 (124):  Call 379  vs  Put 343   →  แทบเสมอ
```

**เรื่อง "คอลนำ" ที่เล่ามาทั้งวันจบลงตรงนี้** — บอกผู้ใช้ทั้งเลขก่อนหักและหลังหัก เขาจะได้เห็นเองว่าอะไรเปลี่ยน

## ขั้น 4 — เส้นไหนนิ่ง เส้นไหนไหล

$$\Delta(\pm n\text{SD}) = \Delta P \pm n\,\Delta\sigma$$

ฝั่งล่างมักดู "นิ่ง" ตอนราคาไหลลงช้าๆ เพราะ ΔP กับ Δσ หักล้างกันพอดี — **แต่นั่นเป็นเรื่องบังเอิญ ไม่ใช่โครงสร้าง** พอราคาเร่ง มันจะไหลตามทันที

```
        ช็อต1    ช็อต2    ช็อต3    ตอนนี้
+2SD    4,193 → 4,186 → 4,180 → 4,158    ไหลลงเร็ว
-2SD    4,030 → 4,025 → 4,024 → 4,014    นิ่ง แล้วขยับตอนราคาเร่ง
```

บอกผู้ใช้ได้ว่าเส้นล่างพอตั้งไม้รอได้ **แต่อย่าบอกว่ามันนิ่งเพราะเป็นแนวรับ** — มันนิ่งเพราะเลขหักล้างกัน ถ้าเคยบอกว่า "นิ่ง" แล้วมันขยับ ให้แก้ตรงๆ พร้อมอธิบายด้วยสมการข้างบน ความน่าเชื่อถือมาจากการยอมแก้

**เช็คว่ากรอบหดจาก theta ล้วนหรือไม่:**

$$\sigma_{\text{ใหม่}} \approx \sigma_{\text{เดิม}} \times \sqrt{\frac{DTE_{\text{ใหม่}}}{DTE_{\text{เดิม}}}} \times \frac{P_{\text{ใหม่}}}{P_{\text{เดิม}}}$$

ถ้าตรงกับค่าจริง = vol ไม่ได้ขยับ (ยืนยันว่าช่อง Vol แช่แข็ง) ถ้าไม่ตรง = มีอะไรเปลี่ยนจริง ต้องหาสาเหตุ

## ขั้น 5 — เทียบ Volume วันนี้ กับ OI เมื่อวาน

สองหน้านี้คนละวัน **แต่เอามาเทียบกันแล้วได้ของที่หน้าเดียวให้ไม่ได้**

| Strike | OI เมื่อวาน | วอลุ่มวันนี้ | อ่านว่า |
|---|---|---|---|
| 4,150 | +155 (churn ~1.0) | 60 | **ของเก่าฝังตัว + วันนี้มาเติม** → ระดับแข็ง |
| 4,175 | แทบไม่มี | **124** | **ของใหม่เอี่ยม ไม่มีฐานเดิม** → ยังไม่รู้ว่าติดไหม |

ระดับที่มีทั้ง OI ฝังตัว **และ** วอลุ่มวันนี้มายืนยัน = แข็งที่สุด
ระดับที่มีแต่วอลุ่มวันนี้ = ต้องรอ OI พรุ่งนี้ (ถ้าสัญญายังไม่ตายก่อน)

## กรอบความซื่อสัตย์

- **วอลุ่มไม่บอกฝั่ง** — สรุปได้แค่ "น้ำหนักเอนไปทาง X เพราะ Y" ห้ามเขียนว่ารู้แน่
- **กล้าฟันได้ ถ้าฟันบนตรรกะที่ตรวจสอบได้** — "จบเกมแล้ว" พูดได้เมื่อมีเลขระยะ SD + งบเวลารองรับ นั่นคือข้อจำกัดเชิงกลไก ไม่ใช่การทำนาย
- **ต่างจากการทำนายราคา** — เราบอกว่า strike ไปไม่ถึง ไม่ได้บอกว่าราคาจะไปทางไหน
- **เจอว่าตัวเองพูดผิดให้แก้ทันที** พร้อมเหตุผล อย่าเงียบ อย่าขอโทษยืดยาว
- **เส้นทั้งหมดตายพร้อมสัญญา** — บอกวันหมดอายุทุกครั้ง อย่าให้เอาเลขข้ามวัน
- ไม่ใช่คำแนะนำการลงทุน · ปิดท้ายด้วยประโยคนี้เสมอ
